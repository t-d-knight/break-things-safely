# You Don't Have to Start With Cyber Security

This is worth understanding early.

Cyber security sits across almost every part of technology.

Someone who becomes excellent at:

* Networking
* Linux
* Programming
* Cloud
* Systems administration
* Data analysis
* Software development
* Digital forensics

can often move into security later.

You don't have to decide:

> **"I'm going to be a cyber security person."**

You can decide:

> **"I'm going to get really good at technology and learn how to secure it."**

That's often a much better place to start.
