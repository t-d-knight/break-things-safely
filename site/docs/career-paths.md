# Where Can Cyber Security Take You?

Cyber isn't one job.

If you enjoy...

| You enjoy...                        | You might like...                      |
| -------------------------------------- | ------------------------------------------ |
| Finding patterns                    | Threat Intelligence                    |
| Solving puzzles                     | Digital Forensics / DFIR               |
| Breaking things                     | Penetration Testing                    |
| Building things                     | Security Engineering                   |
| Writing code                        | Security Automation / Engineering      |
| Networks                            | Network Security                       |
| Catching bad things                 | SOC / Incident Response                |
| Investigating                       | OSINT / Threat Intelligence            |
| Cloud technology                    | Cloud Security                         |
| Rules, risk and communication       | GRC                                    |
| Understanding how attackers operate | Threat Hunting / Detection Engineering |

You don't need to pick one now.

Try things.

You'll eventually find the bits you enjoy and the bits you absolutely don't.

That's useful information too.
