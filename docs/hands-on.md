# Get Hands-On

Reading about cyber security is useful.

Breaking something in a controlled environment is much more useful.

| Platform                                                    | What it is                                            | Cost |
| ------------------------------------------------------------ | ----------------------------------------------------- | ---- |
| [TryHackMe](https://tryhackme.com)                          | Guided, beginner-friendly security labs               | Free tier + paid subscription for full content |
| [picoCTF](https://picoctf.org)                              | Capture-the-flag challenges from beginner to advanced | Free |
| [Hack The Box](https://hackthebox.com)                      | More challenging offensive security labs              | Free tier is limited (shared VPN, no retired machines) — paid subscription for the full library |

| [Cyber Security Roadmap](https://roadmap.sh/cyber-security) | Visual map of the different areas of cyber security   | Free |

### A good first project

Set up a Linux virtual machine.

Run a web server.

Look at its logs.

Generate some failed logins.

Work out what happened.

Then ask:

> **If someone was attacking this machine, what would I see?**

That's cyber security.

You don't need to know the answer beforehand.
